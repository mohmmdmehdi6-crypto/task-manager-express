# RETRO

## What I learned

In this task, I learned about HTTP status codes and how to use them.
I learned how to implement Search and Filter in an API.
I learned how to organize my project files and separate different parts of the code.
I implemented all the API routes and CRUD operations.
I learned how to use Express Router and how to separate routes from controllers.
I learned how to use Controllers to keep the main logic separate from the routes.
I learned how to upload files with Multer and serve them with Express.
I also learned how to save data using a JSON file.
I learned how to validate request data using express-validator.
I learned how to handle errors using customError and errorMiddleware.
I learned how to use middleware to process requests before they reach the routes.
In this project, I improved my understanding of Express Router, Controllers, CRUD, status codes, file upload, persistence, Search, Filter, Validation, Middleware, and Error Handling.
