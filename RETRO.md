# RETRO

## What I learned

In this task, I learned about HTTP status codes and how to use them.

I learned how to implement Search and Filter in an API.

I learned how to organize my project files and put each part of the code in the right file.

I implemented all the API routes and CRUD operations.

I learned how to upload files with Express.

I learned how to connect my API to a JSON file and save data in it.

In this project, I improved my understanding of Express Router, CRUD, status codes, file upload, JSON persistence, Search, and Filter.

## What was difficult

At first, working with JSON files and saving data was difficult for me. I learned how to use `fs` to read and write the JSON file.

I also learned how Query Parameters work for Search and Filter.
